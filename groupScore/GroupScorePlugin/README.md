# 小组积分

![小组积分 · ClassIsland 课堂小组计分插件](cover.png)

给班级大屏课表软件 [ClassIsland](https://classisland.tech) 加一套小组积分管理：
上课铃响，屏幕角落自动冒出一个积分球，点一下展开就能给小组加减分；主界面上还能摆一个实时积分榜。

面向 ClassIsland `2.1` 及以上 · 仅 Windows · 数据只存本机

---

## 功能

- **积分球** — 上课自动出现、下课自动收起；可以设置只在指定科目上课时出现
- **一键加减分** — 预设项自带原因（如「回答正确 +2」），加分红、扣分绿
- **两种加分面板** — *逐个选择*（下拉挑小组再点按钮）/ *全部展开*（每个小组一行，行尾直接点）
- **算到人头** — 指名某个学生加分；不指名就记在小组头上，谁挣的分都查得到
- **撤销上一步** — 点错了立刻撤回，连点就是连续撤销
- **实时积分榜** — 主界面组件，显示前几名，小组颜色一眼区分
- **本周比上周** — 自然周 / 自然月的净增、累计、名次升降
- **自动化** — 5 条行动 + 1 个触发器，可用 ClassIsland 自带的自动化编排积分球与计分
- **拖动记位置** — 球和展开后的面板都能拖，松手后记住，下次上课还在那儿
- **只在上课加分**（默认开）— 防止课后误加；ClassIsland 里没配课表时自动失效，不会把插件卡死

## 安装

### 方式一：从本地安装（推荐）

1. 下载插件包 `groupScore.cipx`
2. 打开 **应用设置 → 插件**，点右上角 `···`（更多设置）→ **从本地安装** → 选刚才那个 `.cipx`
3. **重启 ClassIsland**（安装后必须重启才生效）
4. 再回到 **应用设置 → 插件 → 已安装插件**，确认列表里有「小组积分」且已启用

不用解压、不用找目录 —— 选完文件就完事了，剩下的 ClassIsland 自己解。

> 少数电脑上点「从本地安装」会弹一个 **`GetItemAt failed`** 或「不支持此接口」的错误框
> （调用栈里有 `Avalonia.Win32.Win32StorageProvider`）。那是 ClassIsland 用的文件选择框
> 在那台机器上打不开多选，**跟本插件无关**，换成下面的方式二即可。

### 方式二：解压即用（哪台机器都行）

1. 下载 `groupScore-manual.zip`，解压得到 `groupScore` 文件夹
2. 把**整个文件夹**放进 ClassIsland 的 `data\Plugins\` 下 —— 放完应该是
   `data\Plugins\groupScore\manifest.yml`（文件夹名必须正好是这个 id，别改名）
3. 重启 ClassIsland

没有 `.zip` 只有 `.cipx` 时也能用这招：`.cipx` 本身就是 zip，把它改名成 `.zip` 解压，
按上面的结构放进去即可。**卸载**就是删掉 `groupScore` 这个文件夹。

## 使用

### 小组积分球

上课时自动出现在屏幕角落：

- **单击** 展开操作面板，再点一下收起
- **按住拖动** 换位置 —— 展开后的面板同样能拖，贴到屏幕边会自动收进来
- 面板里：选小组 → 选成员（可选）→ 点一个预设按钮，分就记上了

面板右上角有**样式切换按钮**，随时可以换另一种加分方式（见下表）。默认用哪种在设置页里改。

| | 逐个选择 | 全部展开 |
|---|---|---|
| 长什么样 | 下拉框挑小组 → 下面一排预设按钮 | 每个小组各占一行，行尾就是按钮 |
| 加分步骤 | 2 步（先选组，再点按钮） | 1 步（点哪行就给哪组加） |
| 适合 | 小组多、要指到具体学生头上 | 课上最高频的「看见哪组好就给哪组加一分」 |

### 设置页

`应用设置 → 插件 → 小组积分`，五个标签页：

| 标签页 | 干什么 |
|---|---|
| 小组管理 | 增删小组、改名、配色、调整顺序；也可以一行一个批量建组 |
| 小组成员 | 每个组的学生名单；学生可以转到别的组 |
| 积分操作 | 直接加减分、撤销上一步、查看最近 20 条记录 |
| 历史对比 | 本周比上周 / 本月比上月 |
| 预设与设置 | 常用加分项、悬浮球（自动弹出 / 停靠位置 / 科目筛选 / 面板样式）、加分时段、积分榜条数、一周从周几算、数据导出 |

**首次启动会建好 4 个示例小组和 5 个示例预设**（回答正确 +2、作业优秀 +3、主动发言 +1、纪律扣分 −1、迟到 −2），按班里的实际情况改掉就能用。

### 主界面积分榜

`应用设置 → 组件`，把「小组积分榜」拖到主界面即可。显示前几名在设置页里调（填 `-1` 显示全部）。

## 用自动化编排

除了插件内置的「上课弹出、下课收起」，积分球什么时候出现也可以完全交给 ClassIsland 的**自动化**。
在 **应用设置 → 自动化 → 添加行动** 里能看到一个「小组积分」分组：

| 行动 | 做什么 | 撤销时 |
|---|---|---|
| 显示积分球 | 以收起的圆球状态出现 | 隐藏 |
| 隐藏积分球 | 整个藏起来 | 显示 |
| 切换积分球显示 | 显示 ⇄ 隐藏 | 再次切换 |
| 展开积分球面板 | 跳过点击，直接开面板 | 收起为圆球 |
| 小组加减分 | 给某个小组（或全部小组）加 / 减指定分值 | 记一笔反向量回退 |

还有 1 个触发器：**小组积分达到阈值** —— 某个小组（或任意小组）的积分跨过设定的分数线时触发一次。
配上「小组加减分」行动就能做「冲到 20 分自动再奖 2 分」这种规则。

最省事的用法是只配一条行动并勾上「可恢复」：

```
触发器「上课」 ──> 行动「显示积分球」（勾上「可恢复」）
                          └─ 下课时 ClassIsland 自动执行反向操作 → 隐藏
```

**只配一条，就同时得到了「上课出现」和「下课收走」。**

> **注意**：用自动化之前，请到 设置页 → 预设与设置，把「上课时自动弹出积分球」「下课 / 放学时自动收起」两个勾去掉 ——
> 内置逻辑和自动化是两套独立机制，同时开会互相打架。

## 常见问题

**为什么成员分加起来比小组总分少？**
因为它们不是一回事。分可以只记在小组头上（「全组作业优秀」这类），没有指名到人，
这部分会算作「未指派到个人」。成员页底部会把账明写出来（`成员分合计 5 ＋ 未指派 2 ＝ 组总分 10`）。

**下课后撤销上一步被拦住了？**
「撤销上一步」按钮任何时候都能用。受「只在上课时加分」影响的是自动化行动的**恢复** ——
它不是删记录，而是再记一笔反向量，所以同样走时段检查。想在下课后撤销自动化，先去设置页关掉这个开关。

**数据存在哪？怎么备份？**
存在 ClassIsland 的**插件配置目录**里，默认是 `score-data.db`（SQLite），路径在设置页最底部的「数据」区能看到。
那里还有「导出 CSV」「打开数据目录」「立即保存」三个按钮。备份直接复制那个文件即可。

**能退回旧的 JSON 存档吗？**
可以。删掉 `score-data.db`，再把同目录下的 `score-data.json.migrated-*.bak` 改名回 `score-data.json` 就行。
（从旧版本升级时，原来的 JSON 是**改名留档**而不是删除。）

**为什么设置页那行写着 JSON？**
说明这台机器上 SQLite 没能启用（原生库没加载成功、数据文件损坏或被占用等），插件会**安静地退回 JSON 继续用**，
功能完全不受影响，只是存储格式不同。原因是这么设计的：教室里最坏的结局不是「存储格式老了」，而是「这节课的分没记上」。

## 其它

- **仅 Windows**，**单机**：数据只存本机，不联网、不同步
- 悬浮球位置目前只按主屏钳制，多屏环境下拖到副屏，重启可能被拉回主屏
- 科目筛选是按**科目名**匹配的 —— 之后在 ClassIsland 里给科目改了名，需要回设置页重新勾一次
- 「撤销上一步」的实现是**删掉最后一条记录**，所以撤销之后「历史对比」里的数字会跟着变。这是取舍不是 bug：记录表是唯一事实来源，历史由它派生
